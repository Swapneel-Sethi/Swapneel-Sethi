# Fonts

Subset WOFF files embedded as data URIs in every card SVG, so the typography renders
the same inside GitHub's `<img>` sandbox without any external request.

| File | Family | Use | Licence |
| --- | --- | --- | --- |
| `serif-400.woff` | Instrument Serif Regular | display / names / numbers | SIL OFL 1.1 |
| `serif-italic.woff` | Instrument Serif Italic | italic emphasis | SIL OFL 1.1 |
| `geist-400.woff` | Geist Regular | body copy | SIL OFL 1.1 |
| `geist-600.woff` | Geist SemiBold | repo names | SIL OFL 1.1 |
| `geistmono-400.woff` | Geist Mono Regular | labels / metadata | SIL OFL 1.1 |

Instrument Serif: https://fonts.google.com/specimen/Instrument+Serif
Geist / Geist Mono: https://vercel.com/font
